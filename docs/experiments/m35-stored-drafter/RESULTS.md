# Stored drafter execution migration

Four adopted native publications now carry their authoritative execution graph
and typed drafting protocol. Their complete index files and all 4,556 encoded
tensor parts are unchanged. With the same current target, removing only the new
stage-1 `drafting` member from each actual native composed JSON reconstructs the
complete captured historical canonical bytes. Five integrated model checks pass;
three frozen numerical cases remain negative and reproduce the exact legacy
observations under the same scalar CUDA source. This establishes no migration
regression in the checked observations, not numerical qualification. Current
ID/spec-pin fixtures are updated, and all four publications are installed in
both Sparks’ canonical stores. Original artifacts are retained.

The [aggregate](results.json) records full IDs, source receipts, actual compiler
and CLI identity, every listed-file hash, full index hashes, payload proof hashes
and the actual composed spec digests. The retained R9 CLI published all four
artifacts under exclusive supervised jobs, including source hashing and native
Deep/StoredSpec validation. Runtime composition checks use the later R11
rebinding fix. Raw manifest SHA is separate from the semantic artifact ID.
New private directories/files are 0700/0600; original artifacts and checkpoints
are unchanged. Actual native publication durations were 2.439, 2.238, 25.808 and
52.169 seconds respectively; these are publication observations, not model
performance measurements.

Gemma and DSpark preserve their complete original source identities. Qwen also
retains four existing metadata files now present in the checkpoint directory:
chat template, generation config, tokenizer and tokenizer config. The initial
six-source equality guard caught this difference and stopped progression. Each
added name/size/SHA matches the same approved archive revision `925d7be6…` and
historically pinned archive manifest `f242b94a…`; all original six receipts,
including the exact 47,172-ID list, remain unchanged. The actual ten-source
identity is recorded transparently, with no source projection or new license
assumption. All preprocessing transformations remain identical.

Both Gemma protocols are kind-only `anchored`; depth 3 is a measured default,
not a stored restriction. Qwen is kind-only `mtp`; its selected output binding
owns the paid I32 map. DSpark stores `block`, source maximum 5 proposals and
fill token 128799. Admission, settings and construction use StoredSpec, actual
role geometry and supported execution/resource bounds. Import mappings provide
optional performance preferences, not structural permission.

The first native composition diagnostic found a real MLX cross-target issue:
physical borrowed tensor names still referred to the original target. Generic
rebinding now resolves complete owner roles at the same structural component
site in the actual target. Split parts follow that role; tied aliases must agree,
and missing, foreign or ambiguous replacements refuse. Span-only pre-counting,
existing format/schema bounds and a statically checked funding term cover
multipart expansion before allocation. The original four artifact bytes remain
valid. Same-target canonical bytes are unchanged by this repair.

R9 passed 278 focused native cases; R11 passed 136 affected cases, including
renamed/split roles, tie consensus/refusal, named side sites and part-count bounds.
The final native composition diagnostic executes one inner test with exactly
four expected old full-spec-pin assertions, zero skips and no other failure;
the MLX cross-target assertions pass. This is a schema-transition proof, not a
serving or numerical qualification. Full new canonical identities remain
explicit, historical numerical references are untouched, and no stale grant is
inherited by ignoring `drafting`.

Final native builds passed on both Sparks. The full shared run retained 3,833
positive inner cases and six failures from stale synthetic fixtures. Updating
only those fixtures to state their typed drafting contract and MTP facts closed
all six failures in 77 affected cases, with zero skips. The checked union is
3,839 positive inner cases plus 21 external shared checks; the original failed
run remains recorded. No production change or full-suite rerun was needed for
that fixture repair.

A paired exclusive transfer installed all four publications in Spark A's private
proof store in 37.617 seconds. Full-file hashes and private modes were checked
before hardlink reuse and after transfer. Actual reuse was 16 listed files /
13,745,564,294 bytes; original inode, size and mode were preserved. This transfer
was followed by authenticated canonical promotion on both hosts: 25.081 seconds
on Spark A and 25.727 seconds on Spark B. Each promotion verified full bytes and
private modes, reused 24 listed files by hardlink and retained old artifacts,
including their original inode, size and mode. Raw manifests were checked
separately. Identical bytes retain the native Deep/StoredSpec and role-closure
proofs; no re-import or semantic-ID reimplementation was used.

The final private-store model wave completed seven registrations/eight inner
cases without skips. Spark B passed all five Qwen execution, composition and
approval checks. On Spark A, both Gemma assistants and DSpark completed their
runtime and lifecycle checks but failed the frozen numerical comparisons:
Gemma26 had 15 differing observations (including tokens), Gemma31 had six
(tokens matched), and DSpark had three (heads.1, logits.1 and state.2).

Attribution setup attempts R1 (missing scratch) and R2 (copied-data-path guard)
stopped before model construction or execution. R3 completed the bounded
attribution control using the pre-migration `ee88938d` runtime with
old canonical drafter IDs, the same current targets, identical frozen oracles
and the same generic scalar CUDA change. All three cases completed and remained
FAIL, reproducing all 24 failed keys, actual values and expected values exactly,
with no additional failed assertions. This localizes those observed negatives
to behavior already present without the stored-drafter migration; it does not
turn either run into a numerical PASS or qualify their output. No frozen oracle,
grant or quality bound changed. Broader U3 and the Gemma/DSpark numerical gaps
remain open. Root’s adoption assessment permits this structural migration on
that evidence, without promoting the numerical results. Spark B’s final main
runtime/CLI and affected consumers were restored and rebuilt successfully;
Spark A’s final runtime/CLI relink also passed in two seconds, with unchanged
source guards.
