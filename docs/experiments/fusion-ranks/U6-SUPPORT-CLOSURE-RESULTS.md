# U6 shared-support pass — superseded build

This report preserves the 95 reviewed decisions and 21 passing installed
controls from the shared-support build under their original identities. The
subsequent regression gate found production router nonselection and a mapped
state-access check that rejected a valid joined GDN rewrite. Their reviewed
repairs change build identities. These rows remain historical; they are never
repinned to the repaired source. See [final qualification](U6-FINAL-RESULTS.md)
for the final build and outcome.

data in their backend, and compares genuine selected rewrites with their own
complete alternatives. Production selection retains the cumulatively chosen
program, original source provenance and paid resources through Bind and cache
publication. All 49 registered rewrite/batch patterns have enforced synthetic
match/refusal controls. That inventory does not assert 49 measured model
families or universal shape/format coverage.
