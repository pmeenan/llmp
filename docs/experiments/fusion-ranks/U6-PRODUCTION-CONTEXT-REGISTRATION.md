## Reason and fixed scope

The final adoption audit found that local constructors for original A commands
13–58 did not use normal production planning metadata. Their original keys and
measurements remain experimental evidence and are excluded from production
data. Corrected constructors derive actual policy, bounded addresses, source
external declarations and prepared options through the production helpers.
Stateless ComponentPorts use Prefill without token shape; NormGate and NEOX
retain Decode token context. GDN gates retain Verify and declare their actual
externally supplied F32 token features through the existing Features contract,
with both original gate outputs and no fabricated logits head or token IDs.

The native preflight also exposed an overbroad ComparisonPair guard: it refused
the normal stream callback even with no lane tags. AssignLanes returns before
consulting that callback when tags are empty. The shared fix admits this inert
callback and retains the refusal of nonempty lane tags. A focused regression
requires zero callback invocations, identical complete plans and persistent
Ready keys, and continued lane refusal. This changes the compiler-owned build
identity. All current measurements therefore receive a fresh uniform pass;
no old key or sample is repinned. Runtime arithmetic, kernels, source payloads,
numerical limits and clock policy are unchanged.

The obsolete section/gamma registration guard is removed. Those six commands
can reach their already implemented 52-record sampler; their earlier attempts
collected no samples. Every original failure remains in the results record.
