identities. Its 94 decisions and 21 installed controls were independently
qualified. The subsequent full test-artifact build exposed the standalone

model regression suites did not run on this build. The proper shared-library
repair changes implementation identities, requiring a prospective uniform
refresh rather than repinning these rows. See the
[final U6 qualification](U6-FINAL-RESULTS.md) for the current build and outcome.

program, original source provenance and paid resources through Bind and cache
publication. All 49 registered rewrite/batch patterns have enforced synthetic
